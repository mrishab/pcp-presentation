## What is Decidability

- **Decidable**: there exists an algorithm (TM) that always halts and answers correctly
- **Undecidable**: no algorithm can answer correctly for every input
- This topic is about the **limits of computation**

<div class="slide-author" data-name="Rishab Manocha"></div>

---

## Where PCP Fits

- PCP is a deceptively simple “domino string matching” puzzle
- Yet it can encode arbitrary computation (via reduction from **A<sub>TM</sub>**)
- We'll do a quick example, then sketch why it is undecidable
