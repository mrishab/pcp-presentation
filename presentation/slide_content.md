# Slide Title
A Simple Undecidable Problem

# Slide Bullets
- What does it mean for a problem to be undecidable?
- Can we always determine whether a solution exists?
- Example: matching sequences of domino-like tiles
- Some problems cannot be solved by any algorithm

# Speaker Notes
Imagine you are given a set of domino-like tiles. Each tile has a string on the top and a string on the bottom. The goal is to arrange them so that the top and bottom strings match exactly.

At first, this seems like the type of problem a computer should be able to solve. But this section shows something deeper.

It introduces the idea of undecidability. An undecidable problem is one where no algorithm exists that can always give the correct yes-or-no answer for every possible input.

This matters because it shows a fundamental limit of computation. Computer science is not only about building algorithms. It is also about understanding the boundaries of what algorithms can do.

The domino-style problem in Section 5.2 is important because it gives a simple-looking example of a problem that turns out to be impossible to solve in general.

In the next part, we will see the proof idea showing why this problem is undecidable.
